# 📸 ISC Watermark Tool (v1.1)

Công cụ trực tuyến hỗ trợ chèn Watermark (văn bản & logo), cắt ảnh và tối ưu dung lượng hình ảnh hàng loạt trực tiếp trên trình duyệt.

---

### ✨ Tính năng nổi bật
* **Bảo mật tuyệt đối (100% Client-side):** Mọi thao tác xử lý ảnh diễn ra trên RAM máy tính của bạn, không tải hình ảnh lên bất kỳ máy chủ nào.
* **Chèn Watermark đa năng:**
  * **Văn bản:** Tùy chỉnh màu sắc, cỡ chữ, độ mờ, kiểu lưới chéo hoặc góc, tùy biến mật độ lặp lại.
  * **Logo:** Điểm neo 9 vị trí (Grid Picker), căn chỉnh kích thước và độ trong suốt linh hoạt.
* **Cắt & Tối ưu (Crop & Optimize):** Hỗ trợ tỉ lệ chuẩn mạng xã hội (1:1, 16:9, 4:5, 9:16...) hoặc cắt chính xác theo Pixel.
* **Xử lý hàng loạt:** Xuất toàn bộ ảnh đã đóng dấu thành 1 file `.zip` duy nhất, hỗ trợ nén dung lượng (KB) cho định dạng JPG.
* **Tiện ích thao tác:** Hỗ trợ Hoàn tác (`Ctrl + Z`) / Làm lại (`Ctrl + Y`), kéo thả ảnh, chọn/xóa hàng loạt.

---

### 🚀 Công nghệ sử dụng
* **HTML5 Canvas:** Xử lý đồ họa trực tiếp trên trình duyệt.
* **Cropper.js:** Cắt ảnh tương tác theo tỷ lệ.
* **JSZip:** Đóng gói và nén file ZIP hàng loạt.
